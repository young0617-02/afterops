# 口径声明（F-017 / 验收 A13）：每个数标明「实测 / 设计值 / 未测」

原则：本项目是**离线原型 + 合成单店数据 + 公开论文口径**，没有真实店铺、没有真实流量。
所有数字只允许出现在下面三张表里；表外的数字若被引用，视为未声明口径。

- **实测** = 本机 2026-10-06 一条命令可复跑，附复跑命令。
- **设计值** = 方案 §五 给的目标/阈值，本轮未证明达成。
- **未测** = 明确没做，不外推、不写成结论。
- 本项目不产出任何「分流比率」类口径（A4 禁用语，见 `tests/test_no_false_claims.py`），只用「错承诺条数」这类可核对计数。
