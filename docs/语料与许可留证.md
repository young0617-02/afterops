## 二、许可：分两层说清楚，不混为一谈

| 对象 | 许可 | 原文出处 | 对本项目的含义 |
|---|---|---|---|
| **论文正文（proceedings）** | **CC-BY-NC**（页脚）：`© European Language Resources Association (ELRA), licensed under CC-BY-NC` | PDF p.459 页脚 | 可以引用、可以做映射表，需署名；**NC = 非商业** |
| ACL Anthology 站点对新论文的通用许可 | CC BY 4.0（站点声明，针对论文渲染页） | 站点元信息 | 这是**论文**的许可，**不是数据集**的许可 |
| **JDDC 数据集本身** | **未取得一手条款**（发放页已失效，见 §三） | — | 不得把数据集写成「CC BY 4.0 可自由再分发」 |

> 更正记录：上游方案（`项目方案-MVP原型.md` F-001 行与 §十）把语料许可写成「CC BY 4.0」。
> 复核后确认这是**来源错位**：CC BY 4.0 来自 ACL Anthology 对论文的声明，论文页脚对 proceedings 写的是 CC-BY-NC，
> 而数据集条款在已失效的发放页里。本仓库按「数据集许可待核实」处理，并在 README 的口径声明里同样标注。

**据此采取的姿态**：本仓库**不附带、不镜像、不重分发** JDDC 原始数据；只保留论文文本与逐条映射表。
求职作品集属于非商业展示，引用少量论文内示例对话并标注出处可站得住，但**不对外声称语料可自由再分发**。

## 三、数据文件可达性（8 个入口逐一探测，2026-10-06）

| 入口 | 结果 | 判定依据 |
|---|---|---|
| `jddc.jd.com`（论文声明地址） | 302 → `https://www.jd.com/error2.aspx?from=shopdomain`，页面文字「抱歉!您访问的页面失联啦」 | 页面不存在 |
| `jddc-challenge.s3.cn-north-1.jdcloud-oss.com/JDDC/train.json` | 404，响应体 `<Code>NoSuchBucket</Code>` | 桶已不存在 |
| `data.aichengxing.com`（AI Challenger 数据平台） | DNS 解析失败 `getaddrinfo failed` | 本机不可达（平台通常还需登录） |
| `huggingface.co/api/datasets?search=jddc` | 连接超时 | 本机网络不通 |
| `hf-mirror.com/api/datasets?search=jddc` | 200，响应体 `[]` | 镜像无该数据集 |
| `modelscope.cn/api/v1/datasets?Query=JDDC` | 200，结果列表为空 | 境内站点无该数据集 |
| `aclanthology.org/2020.lrec-1.58/` 与 `.pdf` | 200 | 论文可核对，不含数据文件 |

对照事实（同机同时间窗）：`pypi.org`、`www.jd.com` 正常 200 → 不是断网，是入口没有数据。
复跑命令：`python scripts/fetch_jddc.py probe --timeout 12`。

## 四、论文里能硬引用的数（含页码）

- 规模（Table 2/3，p.461）：会话 **1,024,196**；话轮 **20,451,337**；词 150,716,172；平均 20 轮/会话，最长 83，最短 2。
- 意图标注（§3.2，p.461）：自建分类器 **289 个意图**，训练样本 578,127 条（由职业客服标注），分类准确率 93%。
- Top-5 意图（§3.2，p.462）：`Warranty and return policy`（9.2%）、`Delivery duration`、
  `Change order information`、`Check order status`、`Contact customer service`。
- 示例对话（p.460，含真实商家-顾客话轮）：改地址（同市可改/跨市需重新下单）、取消订单后退款到账时效
  （微信零钱 1 个工作日；储蓄卡 1-7；信用卡 1-15）。→ 这组句式被直接用作本项目的高危用例来源（见 `意图体系.md`）。
- 数据处理（§3.1，p.461）：去重、脱敏（数字替换为 `<NUM>`，订单号替换为 `<ORDER-ID>`）、jieba 分词。
  → 本项目清洗脚本保留这两个特殊 token，不做二次归一。

## 五、年代漂移声明（方案 R2）

JDDC 采集自 2018–2019 年京东售后场景，论文 2020 年发布。**不假装它是 2026 年的售前对话**。
本项目对它的用法限定在两处：① 高危/时效类句式的真实来源；② 意图体系映射的左值来源。
多轮/DST 维度如需补充，方案建议引 CrossWOZ；本次未引入（见待补清单）。
