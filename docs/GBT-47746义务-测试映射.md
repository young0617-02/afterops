## 覆盖边界（这张表不声称的东西）

1. 本表覆盖的是**机制层合规**（有没有拦截、有没有留痕、有没有出口），不声称覆盖标准的全部要求；
   标准里与标识、告知、数据合规相关的条款本项目未实现（见 `待补与歧义清单.md`）。
2. 用例跑在**合成单店 + 自标 golden set** 上，没有真实店铺与真实流量；因此「遵守」的含义是
   「机制在受控输入下按设计工作」，不是「线上合规」。
3. 服务编排层（启动/停止/健康检查）保证的是**运行期不产生脏状态**（端口释放、无孤儿、审计哈希链完整、
   收尾在主线程），它不属于国标四条义务的任何一条，本表不把它算作合规证据。
4. 高危意图判定基于规则关键词，诱导句式的词典覆盖不全时会漏（`T4` 档意图 Top-1 实测 77.5%）；
   漏判的兜底仍是第二道锁 + 每轮人工出口，而不是分类器本身。
