# 工单内部备注

- 验证时间：2026-11-05
- 范围：客服/店主在人工工单内添加仅员工可见的备注
- 迁移：`b6d8f0a2c4e6`（`handoff_notes`）

## 行为

1. 后台「人工工单 → 查看会话」中新增「内部备注（顾客不可见）」区域，店主与客服均可添加，内容 1–1000 字。
2. 备注写入独立 `handoff_notes` 表，关联工单、商家、作者与时间；不写入顾客 `messages`，顾客聊天历史与售后页不可见。
3. 工单详情接口返回按时间排序的备注列表（作者邮箱、内容、时间）；新增备注后可继续查看完整会话。
4. 待接管、处理中、已解决工单都可补备注；备注不会改变工单状态、接管人或最近回复。
5. 每次新增写 `handoff_note_added` 审计，包含工单、备注 ID、操作人与内容长度；备注正文只存业务表，不写审计载荷。
6. 空内容或超过 1000 字返回 422；工单不存在返回 404；未登录返回 401。
7. 备注不发送站内通知或邮件，不会打扰顾客。

## 边界

- 备注只能新增，不能编辑、删除或撤回；没有草稿。
- 没有 @提醒、附件、富文本、标签或按备注搜索；工单搜索仍只匹配顾客消息/最近回复。
- 顾客完全不可见，也不会收到通知；备注不作为对客回复。
- 所有员工都能查看同一商家工单的全部备注，没有按角色/工单权限细分。
- 审计只记录备注 ID 与长度，不记录正文；需要正文时查备注表。
- 没有备注导出或保留期限策略；工单删除时备注随外键级联删除。
