# 聊天申请退货/换货

- 验证时间：2026-11-03
- 范围：聊天识别退货/换货动作、创建待审核退货申请、售后页同步显示
- 需求变更：PRD v0.2 明确允许 AI 创建退货/换货申请，但不执行退款/换货

## 行为

1. 只有明确动作短语（如「我要退货」「申请换货」「帮我退货」）才进入 `RETURN_REQUEST`；「耳机能退吗」仍是 `RETURN_POLICY` 政策咨询。
2. 必须提供订单号；校验订单归属、状态为已签收/已完成、支付状态允许、无进行中的退货申请。
3. 创建退货申请（`requested`），默认退款退货；文本含「换货」时 resolution 为 `exchange`。
4. 回复只说明「已提交退货/换货申请，等待店主审核；审核通过后告知寄回地址」，不承诺退款或审核结果。
5. 聊天响应新增 `returns` 数组；前端显示「退货 #id · 退货退款/换货 · 等待人工审核」；售后进度页同步可见。
6. 退货创建在 `SAVEPOINT` 内执行（`create_return(commit=False)`）；业务校验失败只回滚退货片段，不影响会话消息与审计。

## 边界

- 聊天退货必须一次性提供订单号和明确动作；不做多轮「确认/取消」状态机。
- 不支持聊天上传凭证；附件仍需在售后页补充。
- 退货审批、回寄、收货、退款/换货执行仍全部由店主操作。
- 换货仍为同款同数量；不换 SKU、不补差价。
- AI 创建的是待审核申请，不是退款或换货执行；资金动作边界不变。
