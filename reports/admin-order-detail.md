# 后台订单详情

- 验证时间：2026-11-04
- 范围：客服/店主查看单笔订单的商品、支付、退款、物流、提案与退货
- 入口：后台订单履约页 → 查看详情

## 接口

- `GET /api/admin/orders/{order_no}`：商家内订单详情，客服与店主可读。
- 返回：
  - 订单状态/支付/履约、顾客与收货地址、金额明细；
  - 商品行（SKU/标题/数量/单价/小计）；
  - 支付流水（provider、金额、状态、支付时间）；
  - 退款/补偿账本（提案 ID、金额、状态、执行时间）；
  - 最近运单与全部物流节点；
  - 关联售后提案（类型、状态、金额、来源、执行引用/错误）；
  - 关联退货单（状态、退款/换货、换货 SKU）。

## 边界

- 只读详情，不提供后台直接退款/改地址入口；这些仍走提案。
- 单订单一次返回全部关联数据，无分页；历史提案/退货数量很大的订单会较长。
- 不展示顾客地址簿、通知历史或完整聊天记录（聊天在工单详情）。
- 不包含真实 PSP 结算、发票、税费或会计凭证。
