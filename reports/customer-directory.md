# 后台客户目录与历史

- 验证时间：2026-11-04
- 范围：客服/店主按手机号、姓名、邮箱检索客户，查看订单/售后/退货历史
- 入口：`/admin` → 客户

## 接口

- `GET /api/admin/customers?q=&limit=50`：商家内搜索客户，返回订单数、最近下单、售后数、待审提案、进行中退货。
- `GET /api/admin/customers/{id}`：客户档案 + 最近 20 单订单、20 条提案、20 条退货。
- 客服与店主均可读；无写接口。

## 边界

- 只读目录，不支持在客户档案内直接退款/改地址；这些动作仍走提案。
- 搜索最多返回 50 个客户；详情订单/提案/退货各最近 20 条，无完整分页。
- 按手机号/姓名/邮箱子串搜索，不做模糊音/拼音/脱敏导出。
- 不展示客户地址簿与站内通知历史。
- 无客户合并/删除/导出；PII 访问仅限已登录客服/店主。
