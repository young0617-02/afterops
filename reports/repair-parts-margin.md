# 维修配件成本与毛利

- 验证时间：2026-11-12
- 范围：完成维修时记录配件成本与说明；后台维修卡展示成本/毛利，财务「售后收款」展示维修成本与毛利合计；顾客端不返回成本
- 迁移：`f6b8d0e2c4a6_repair_parts_cost.py`，`repair_requests` 新增 `parts_cost_cents`、`parts_note` 与非负约束

## 行为

1. 店主完成维修并寄回时可填写配件成本（元）与配件说明；不填为 0，负数与非数字被拒绝。
2. 完成操作在同一事务写入成本字段与审计 `repair_completed`（含成本、说明）；顾客通知只含维修完成与寄回信息，不含成本。
3. 后台维修列表/操作响应返回 `parts_cost_cents` 与 `parts_note`；顾客维修接口返回 `null`，不泄露成本。
4. 后台维修卡显示「配件成本 X 元 · 维修毛利 Y 元 · 说明」，毛利 = 已报价金额 − 配件成本；无报价的维修只显示成本。
5. 财务「售后收款」在维修费合计旁新增维修成本与维修毛利（按月窗口聚合，按已收款维修单关联成本），毛利可为负。
6. 配件成本不进入订单应付、退款、发票、售后收款金额或净额；只作为维修成本口径用于内部毛利展示。
7. 历史维修未记录成本，迁移默认 0；这些记录会把维修毛利显示为等于维修费。

## 边界

- 只在完成维修时录入成本；无逐配件明细、库存扣减、采购价、人工工时或运费成本，毛利口径较粗。
- 历史维修成本默认 0，财务毛利会被高估；没有成本回填或补录入口。
- 顾客端看不到成本；后台客服角色可只读查看，无成本修改权限（仅店主完成维修时写入）。
- 成本不进入订单应付、退款、发票和净额；售后收款台账仍只把维修费作为收入。
- 配件说明最多 500 字，不识别图片/发票；成本可为 0 或高于报价（负毛利），不做异常告警。
- 财务成本/毛利按售后收款创建时间窗口聚合，成本可能在窗口外完成/补录而不匹配。
