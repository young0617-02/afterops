# 顾客售后风险画像

- 验证时间：2026-11-10
- 范围：后台客户档案新增 90 天售后风险画像，按退货次数/退货率、顾客主动取消补差换货、扣减申诉与顾客责任次数给出透明等级与原因；只提示，不自动拒绝售后
- 迁移：无（基于现有订单、退货、申诉与责任判定数据实时计算）

## 行为

1. 客户档案接口 `GET /api/admin/customers/{id}` 新增 `after_sales_risk`：等级、原因列表、窗口天数、订单数、退货次数、退货率、取消补差换货次数、扣减申诉次数、顾客责任次数、最近退货时间。
2. 统计窗口固定 90 天：
   - 订单：窗口内已支付/部分退款/已退款订单数，作为退货率分母；
   - 退货：窗口内创建且未被撤回/驳回的退货申请数；退货率 = 退货次数 / 订单数，最高 100%；
   - 取消补差换货：仅统计顾客主动取消（`exchange_cancelled_by=customer`）；
   - 扣减申诉：窗口内创建的全部申诉；
   - 顾客责任：窗口内至少一条退货明细判为顾客责任的退货单数（按单去重）。
3. 等级规则（固定阈值）：
   - 高：退货 ≥3 次，或顾客主动取消补差换货 ≥2 次，或扣减申诉 ≥2 次，或顾客责任 ≥2 次；
   - 需关注：退货 ≥2 次，或任一取消换货/申诉/顾客责任记录；
   - 正常：其余。
4. 原因文案由命中的计数生成，例如「90 天内退货 3 次（订单 3 单）」「顾客主动放弃补差换货 1 次」，便于客服核对，不使用不可解释的评分。
5. 后台客户档案展示「售后风险」徽章、退货/订单/退货率与三类计数；无风险时显示「近 90 天未发现售后风险信号」。
6. 风险画像只读，不影响退货审批、提案、AI 回复或自动分配；不提供拉黑、自动拒绝或限制下单。

## 边界

- 窗口与阈值是固定代码常量，不按商家/类目配置；退货率最高按 100% 展示，多次退货可能被截断。
- 仅统计窗口内数据；退货被撤回或驳回不计入退货次数，但订单仍计入分母，可能拉低退货率。
- 风险等级是规则引擎结果，不是机器学习评分；不区分商品价格、退货原因合理性、是否首次购买或商家责任占比。
- 只在客户档案详情展示，未进入退货审核卡片、工单分诊或 AI 回复；不触发自动动作。
- 顾客责任以质检责任判定为准；未判定或物流/商家责任不计入。
- 大客户/高频正常退换（如服装试穿）可能被标为高风险，需人工结合原因判断。
