# 后台搜索与分页

- 验证时间：2026-11-03
- 范围：提案列表搜索/游标分页、履约订单搜索、顾客订单状态筛选/分页

## 接口

- `GET /api/admin/proposals?status=&q=&before_id=&limit=50`
  - `q` 为纯数字时按提案 ID 精确查；否则搜索提案载荷文本（订单号等）。
  - 游标 `before_id` 按 id 倒序翻页，最多 200/页。
- `GET /api/admin/orders?open_only=&q=&limit=50`
  - `q` 匹配订单号、收货人、收货手机号。
- `GET /api/store/orders?q=&status=&before_id=&limit=20`：顾客订单号搜索、状态筛选与游标分页。
- `GET /api/store/addresses/last`：最近订单收货地址，用于结算预填。

## 前端

- 售后提案页：搜索框 + 状态筛选 + 「加载更多提案」。
- 订单履约页：搜索框 + 待履约/全部范围。
- 顾客订单页：订单号搜索 + 状态筛选 + 「加载更多订单」。
- 购物车结算：自动预填最近收货地址，仍可手工修改。
- 搜索条件与筛选组合生效。

## 边界

- 提案搜索只搜载荷文本与 ID，不搜顾客姓名/手机号（提案载荷不含这些字段）。
- 游标分页按 ID 倒序，不提供页码/总数；前端以返回 50 条判断“可能还有更多”，可能多请求一次空页。
- 后台履约订单搜索最多返回 50 条，无分页；顾客订单每页 20 条、只按订单号搜索，可能多请求一次空页；最近地址取最近一单，不做地址簿。
