# AI 退款进度查询

- 验证时间：2026-11-03
- 范围：顾客在聊天中查询订单的售后/退款进度
- 能力：`REFUND_STATUS` 意图 + 只读售后工具

## 行为

- 识别「退款到账 / 退款进度 / 退款状态 / 多久到账 / 钱什么时候退 / 几天到账」。
- 校验订单归属；读取该订单最新售后提案（最多 3 条历史）。
- 回复原型：
  - 无申请：`订单 … 暂无售后申请记录。`
  - 待审：`退款申请，金额 899.00 元，当前状态：等待人工审核。`
  - 已执行：`退款申请已执行，金额 … 元，处理引用 …。到账时间以支付渠道为准，我不承诺具体到账时间。`
  - 驳回：`申请未通过，原因：…。`
- 引用 `proposal:{id}`；金额/处理引用进入数字白名单，LLM 改写不能新增或遗漏。

## 边界

- 只读取本系统售后提案与退款账本状态；“已执行”不等于银行已入账，回复不承诺到账时间。
- 只展示最新提案详情，历史最多 3 条出现在工具数据中；不做多笔退款汇总。
- 无提案时只说明无记录，不推断“没退款”或承诺补处理。
- 若店主驳回原因本身含承诺词，最终回复仍会经过承诺扫描并可能回退。
