# 售后时间线补全与后台客户档案

- 验证时间：2026-11-10
- 范围：售后时间线补充维修报价、维修费支付、换货补差支付、退款到账事件；后台客户档案新增同一套售后时间线
- 迁移：无（只读聚合现有表）

## 行为

1. 顾客时间线新增维修报价事件：报价发送、接受/拒绝、维修费支付；标题与金额/说明/支付引用来自维修单。
2. 新增换货补差价支付事件：金额与 `EXS-` 支付引用，状态为已支付。
3. 退款结算成功后在原「退款已执行」之外增加「退款已到账」事件，展示到账金额与渠道引用。
4. 后台新增 `GET /api/admin/customers/{id}/timeline?limit=50`：校验客户属于当前商家，复用顾客售后时间线聚合，返回同样的事件字段。
5. 后台客户档案新增「售后时间线」区块，展示类型徽章、标题、说明、时间与订单号；时间线随档案同时加载。
6. 顾客售后页时间线仍展示完整聚合事件，新增类型「维修报价」徽章。

## 边界

- 后台客户时间线只读聚合，不能从时间线直接操作单据；无独立权限细分，客服/店主均可查看。
- 时间线仍无游标分页，后台与顾客均按固定 limit 截断；超长历史需要依赖列表页。
- 退款渠道失败没有独立时间字段，因此只增加成功到账事件；失败仍在原退款事件状态中体现。
- 维修报价/补差事件来自当前记录字段，不保留每次改价或失败重试历史。
- 时间线不包含正向订单、支付、发货节点；也不展示附件缩略图或操作人。
