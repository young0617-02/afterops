# 人工工单顾客上下文

- 验证时间：2026-11-05
- 范围：客服在工单会话中直接查看顾客订单/售后摘要与最近订单
- 依赖：现有客户目录、订单、售后提案、退货数据；无新迁移

## 行为

1. 工单详情接口在原有消息与内部备注之外返回 `customer_context`：
   - 历史订单数、最近下单时间；
   - 售后单总数、待审提案数、进行中退货数；
   - 最近 3 笔订单（订单号、状态、支付状态、履约状态、应付金额、下单时间）。
2. 后台「人工工单 → 查看会话」顶部展示摘要与最近订单，客服无需切换到「客户」页搜索。
3. 数据复用客户目录聚合逻辑，按工单所属商家与顾客读取；工单不存在返回 404，未登录返回 401。
4. 只读，不改变工单、订单或售后状态；不新增审计事件。
5. 最近订单只取 3 笔；订单状态用现有中文标签展示。

## 边界

- 只展示摘要与最近 3 笔订单，不展示完整客户档案、订单明细、物流轨迹或退款账本。
- 统计为顾客全生命周期计数，不按当前工单或时间窗口过滤；没有 CSAT、LTV、复购率等指标。
- 没有跳转到客户档案/订单详情的直接入口，也没有刷新按钮或实时更新；重新展开会话才重新拉取。
- 只读，不写审计；不改变任何业务状态。
- 仍展示工单已有的顾客手机号/姓名；没有脱敏开关或按角色隐藏。
- 没有多顾客合并、家庭账号或跨商家身份识别。
