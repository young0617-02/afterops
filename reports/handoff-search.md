# 人工工单搜索

- 验证时间：2026-11-05
- 范围：后台按工单号、顾客手机号/姓名、最近消息搜索工单
- 背景：工单队列按优先级排序且限 50 条，积累较多紧急工单后新普通工单可能不在首屏；搜索可按工单号直达

## 行为

1. `GET /api/admin/handoffs` 新增 `q` 参数（最多 80 字符）。
2. `q` 匹配：工单号中的数字部分（如 `TK-000195` → 195）、顾客手机号、顾客姓名、最近用户消息、最近回复。
3. 后台「人工工单」工具栏增加搜索框；提交后与状态/优先级筛选共同生效。
4. 搜索仍受 `limit` 限制，默认 50 条。
5. 列表加载带请求序号，较早的未过滤响应不会覆盖较新的搜索结果。

## 边界

- 子串匹配，不区分大小写，没有分词、相关性排序或模糊纠错。
- 数字匹配只取第一段可解析数字并限制 18 位；非数字关键词只匹配文本字段。
- 只搜索最近用户消息/回复，不搜索完整会话消息或内部备注。
- 搜索不改变优先级排序，也不导出结果。
