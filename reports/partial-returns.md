# 部分退货

- 验证时间：2026-11-04
- 范围：多商品订单只退部分商品、按商品数量退货、部分退款金额与按量回补
- 迁移：`4d66f438a712`（`return_items`，历史退货回填为整单）

## 行为

1. 顾客在售后页选择已签收订单后，可勾选需要退回的商品；默认全选，至少保留一件。
2. `return_items` 保存退货申请与订单明细的对应关系、SKU 快照、标题快照与数量。
3. 顾客端只按商品勾选，提交时数量取订单数量；API 支持按数量部分退货（如买 2 件退 1 件）。
4. 部分退款金额 = 所选商品小计 − 订单折扣按商品金额比例分摊；运费仅在整单退回时退。
5. 整单退回（未传 `items` 或全选）保持原逻辑：退款剩余可退金额（含运费）。
6. 退款金额不超过剩余可退金额；分摊后不足 1 分时拒绝并提示人工处理。
7. 收货回补只回补所选商品与数量，未退商品库存不变。
8. 换货仍要求整单退回；跨 SKU 换货仍限单商品订单。
9. 审计事件 `return_requested` 记录 `partial` 与所选商品；`return_received` 记录 `refund_scope`（full/partial）与 `refund_amount_cents`。
10. 聊天退货未指定商品时默认整单，行为不变。

## API

`POST /api/store/returns` 新增可选字段：

```json
{
  "order_no": "ORD-...",
  "reason": "只退耳机",
  "items": [{ "sku": "SKU-NCM-001", "qty": 1 }]
}
```

- 不传或空数组：整单退回。
- 商品必须属于该订单；数量 1..订单数量；SKU 不得重复。
- 退货单响应与列表新增 `items: [{ sku, title, qty }]`。

## 边界

- 顾客 UI 只支持“按商品勾选整件”，不支持在页面上改数量；按数量部分退货只能走 API。
- 退货原因与凭证仍是整单级，不支持每个商品单独填写原因或上传凭证。
- 禁退类目仍按整单判断：订单中只要有一件属于禁退类目，整单不能提交退货，即使只勾选其他商品。
- 部分退款按订单折扣分摊，不按优惠券/单品折扣精确归属；运费只在整单退回时退。
- 换货仍要求整单退回；不支持只换其中一件或部分数量换货。
- 退货状态仍是整单状态；没有“部分商品已收货/部分退款”的中间状态。
- 退款仍需店主审批；部分退货可能产生多笔退款提案，财务对账按提案逐笔记录。
- 回补只恢复库存数量，不做质检、残次品库或按商品处置。
